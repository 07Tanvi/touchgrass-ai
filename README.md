# 🌿 TouchGrass AI

**Find your outside.**

TouchGrass AI is a simple outdoor activity planner powered by a locally running open-weight AI model. It helps people take a break from screens and reconnect with the world around them.

## ✨ Features
- Choose your current mood.
- Select how much time you have.
- Choose your preferred outdoor setting.
- Get personalized activity suggestions from a local AI model.

## 🛠️ Built With
- HTML, CSS and JavaScript
- Ollama
- Qwen 2.5 1.5B open-weight model

## 🚀 How to Run
1. Install [Ollama](https://ollama.com/download/windows).
2. Run `ollama run qwen2.5:1.5b` in your terminal to download the model.
3. Start a local server in the project folder with `python -m http.server 8000`.
4. Open `http://localhost:8000` in your browser.
5. Make sure Ollama is running locally, then request an outdoor activity.

## 🌎 Why This Project?
TouchGrass AI encourages people to spend less time scrolling and more time outdoors. It uses a locally running open-weight model, so the activity suggestions can be generated on the user's own computer.
